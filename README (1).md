# Peta Konsep Laju Reaksi (SMA/MA Kelas XI)

Peta konsep interaktif berbentuk potret, hierarkis dari atas ke bawah dengan kata penghubung pada setiap garis. Situs statis satu halaman, tanpa build.

- **Mode Jelajah:** ketuk konsep untuk melihat penjelasan dan jalurnya.
- **Mode Latih:** pilih kata penghubung yang tepat dan dapatkan umpan balik.

## Deploy ke Vercel lewat GitHub
1. Upload `index.html`, `vercel.json`, dan `README.md` langsung ke akar repositori GitHub (bukan di dalam folder).
2. Di vercel.com pilih Add New > Project, import repositori, Framework Preset: Other, lalu Deploy.
